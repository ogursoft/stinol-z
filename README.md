# Stinol 102L Smart Refrigerator Controller v1

Упрощённая монолитная версия контроллера холодильника Стинол-102L.

## Отличия от v2

- Единый файл `stinol_v1.ino` — всё в одном месте
- Простой термостат без FSM
- Базовый WiFi с автопереподключением
- Минимальный веб-интерфейс
- Без аварийного цикла, дебаунса, системы тревог

## Сборка

```bash
pio run -t upload
pio run -t uploadfs
```
